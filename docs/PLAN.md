# Lancat：完整计划 v1.1（2026-10-09 定稿）

## 0. 产品定位
局域网内零配置、零确认的即时分享工具：文件、文本、动态表情。默认常驻在屏幕边缘，悬停即开，离开即收。界面和动效以 macOS 原生风格为准。

## 2. 技术栈
| 层 | 选型 |
|---|---|
| 应用外壳 | Tauri 2 |
| 核心 | Rust：tokio、axum（HTTP/WebSocket）、mdns-sd、socket2 |
| 存储 | SQLite（rusqlite） |
| 前端 | Svelte 5 + TypeScript + Vite |
| 动画 | CSS spring + Motion One |
| 表情 | dotLottie（ThorVG wasm）；默认表情库 Noto Animated Emoji（CC BY 4.0）；支持导入 .tgs |
| 原生能力 | windows crate（Win32/OLE/DWM）；objc2（NSWindow/NSGlassEffectView） |
| 系统插件 | tauri-plugin-autostart、tray、single-instance、updater（可选） |

不选的方案：Electron（太重）；Flutter（空闲内存偏高，没有原生玻璃材质）；Swift 加 WinUI 双原生（工作量翻倍）。

## 3. 架构
```
┌──────────── 前端 Svelte（WebView）────────────┐
│ 隐藏条 │ 聊天弹窗 │ 表情面板 │ 设置 │ 托盘菜单 │
└──────────────────┬───────────────────────────┘
                   │ Tauri IPC（命令 + 事件）
┌──────────────────┴──── Rust 核心 ─────────────┐
│ Discovery │ Transport │ Session/Store │ Dock  │
│ mDNS+UDP  │ HTTP+WS   │ SQLite        │ 原生窗口│
└───────────────────────────────────────────────┘
```
- 两个窗口：
  - dock-strip：隐藏条，透明、置顶、不出现在任务栏，宽 4–6px
  - panel：聊天弹窗
- WebView 只负责显示；网络、文件读写和状态都在 Rust 里处理

## 4. 网络协议
- 端口：TCP 47820 收发数据；UDP 47820 广播兜底；mDNS 用 5353
- 发现：
  - mDNS 服务名 `_lancat._tcp.local`，TXT 记录里带 `id/name/os/ver/avatar_hash`
  - 每 5s 发一次 UDP 广播心跳，应对屏蔽组播的网络
  - 15s 收不到心跳就判定离线
  - 多网卡时每张网卡分别广播；自动排除虚拟网卡（VMware、WSL、Docker）
- 设备身份：首次启动生成 UUID，持久保存；显示名默认是主机名
- 消息：每对设备之间保持一条 WebSocket 长连接，消息为 JSON，类型有 `text`、`emoji`、`file_offer`、`typing`、`ack`
- 文件：
  - 用 HTTP `PUT /files/{transfer_id}/{chunk}` 分块传，每块 4MB，多块并发
  - 用 Range 实现断点续传，用 BLAKE3 做校验
  - 收到的文件直接写入接收目录；重名时自动改名
- 防火墙：Windows 首次运行时请求一次管理员权限添加入站规则（只问这一次）

## 5. 交互设计
- 隐藏条：
  - 停在屏幕边缘的一条细线，半透明；有未读消息时高亮或轻微脉动
  - 停靠的边和高度可以拖动调整，多显示器时可选在哪块屏幕
- 弹出：
  - 悬停约 150ms 后弹出，用 spring 动画（stiffness 300、damping 24）从边缘滑出，同时带一点缩放
  - 拖文件进入隐藏条感应区时立即弹出
- 收起：
  - 鼠标离开约 800ms 后回弹收起，时长可调
  - 以下情况不收起：输入框有焦点、表情面板打开、正在传输、右键菜单打开、窗口被钉住
- 弹窗布局（约 360×520）：
  - 左侧：设备头像栏，带在线点和未读数
  - 右侧：当前设备的会话
  - 底部：输入框、表情按钮、附件按钮
- 拖放发送：
  - 拖到某个头像上：发给这一台
  - 拖到会话区：发给当前会话
  - 拖到顶部的“全部”：群发给所有在线设备
  - 也可以按住 Shift 多选设备后发送
- 表情面板：
  - 二级玻璃浮层，按分类切换，带最近使用，支持搜索
  - 单独发一个表情时显示为 160px 的大号动态贴纸

## 6. 视觉
- 材质：

| 平台 | 方案 |
|---|---|
| macOS 26+ | NSGlassEffectView |
| macOS 13–15 | NSVisualEffectView |
| Windows 11（最低版本） | Acrylic/Mica + CSS 折射高光 |

- 字体：macOS 用 SF Pro；Windows 用 Segoe UI Variable 加 PingFang 的替代字体（HarmonyOS Sans 或 MiSans），整体对齐 macOS 观感
- 跟随系统的深色/浅色模式和强调色
- 动效原则：只动画 transform 和 opacity，保持 60/120fps

## 7. 性能和可用性指标
| 指标 | 目标 |
|---|---|
| 安装包 | < 15MB |
| 空闲内存 | < 50MB（Windows）/ < 40MB（macOS） |
| 空闲 CPU | ≈ 0%；窗口隐藏时暂停渲染和动画 |
| 冷启动到可被发现 | < 2s |
| 千兆局域网传输 | ≥ 100MB/s |
| 稳定性 | 断线自动重连；IP 变化或休眠唤醒后自动重新发现；单实例运行 |

## 8. 安全底线（免认证前提下）
- 收到的文件永不自动执行或打开
- 只在局域网网段监听，拒绝公网地址
- 可选的设备黑名单
- 可选的 TLS 加密（自签证书，不认证，只防抓包）
- 限制单个文件大小和速率（可关闭），防止磁盘被写满

## 10. 风险
| 风险 | 应对 |
|---|---|
| 隐藏条在 Windows 上收不到拖放事件 | 放在 M0 第一个验证；备选方案是全局鼠标钩子加拖放状态检测 |
| 企业网屏蔽组播和广播 | 支持手动输入 IP，加子网扫描兜底 |
| WebView 内存超出目标 | 隐藏时卸载表情模块，并限制动画数量 |
| Telegram 表情版权 | 只内置 Noto 表情，.tgs 由用户自己导入 |

## 11. 已确认（2026-10-09）
1. 支持手机：Android 和 iOS 都做，放在 M5
2. 停靠位置：可以选屏幕的边和高度
3. 接受同局域网任何人直接发送，另外提供黑名单
4. 最低系统版本：Windows 11 起，不做 Win10 降级；macOS 13+
5. 聊天记录永久保存，可一键清空
6. 接收目录可自定义，默认用系统下载目录
7. 应用名：Lancat

## 12. 移动端说明
- iOS：后台只能短暂运行，只有 App 在前台时才能被发现和接收；可以通过分享扩展发送
- Android：前台服务常驻，可以后台接收，耗电低；通知栏显示在线状态
- 两端共用 Rust 核心和协议，表情和会话 UI 也复用
